# ✨ Node.js Hello World Function

A minimal example function returning a **Hello World!** response.

## 🧰 Usage

### GET, POST, PUT, PATCH, DELETE /

Returns a text greeting.

**Response**

Sample `200` Response:

```text
Hello World!
```

## ⚙️ Configuration

| Setting           | Value         |
| ----------------- | ------------- |
| Runtime           | Node (18.0)   |
| Entrypoint        | `src/main.js` |
| Build Commands    | `npm install` |
| Permissions       | `any`         |
| Timeout (Seconds) | 15            |

## 🔒 Environment Variables

No environment variables required.
